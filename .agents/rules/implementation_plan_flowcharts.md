# Implementation Plan Rule

Whenever the user requests a new feature or complex change that warrants an implementation plan, you MUST include a **Simple Text Flowchart** (using standard markdown lists and text arrows like `->`) within the plan. 
Do NOT use Mermaid. The flowchart should clearly illustrate the architecture, data flow, or logical steps of the proposed changes so that the user can learn and visually understand how the system works easily.
